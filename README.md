# Умный кредитный кабинет предпринимателя

Веб-прототип кредитного кабинета для малого и микробизнеса. Клиент может изучить кредитные продукты, обратиться к ИИ-ассистенту, подать заявку и отслеживать её статус. Для банковского специалиста предусмотрен просмотр заявок и отдельное принятие решения.

## Технологический стек

### Frontend
- HTML5 — структура интерфейса.
- CSS3 — стили, адаптивная вёрстка, светлая и тёмная темы.
- JavaScript (ES6+) — логика интерфейса и работа с API.
- React 18 — компоненты и состояние приложения; подключается через CDN.
- Babel Standalone — преобразование JSX в браузере.
- Tailwind CSS CDN — дополнительные utility-классы.
- Lucide — иконки.
- Inter — основной шрифт.

Отдельная сборка frontend через npm не требуется. `package.json` содержит зависимость `ollama`, но frontend не запускается через `npm start`.

### Backend
- Python 3.12 — рекомендуемая версия Python.
- FastAPI — REST API.
- Uvicorn — ASGI-сервер.
- Pydantic — проверка входных данных.
- SQLAlchemy Async — асинхронный доступ к данным.
- aiosqlite — SQLite через асинхронный драйвер.
- HTTPX — HTTP-запросы к Ollama.

### Хранение данных и ИИ
- SQLite — хранение заявок в файле `backend/credit_pipeline.db`, создаваемом при запуске backend.
- Ollama — локальный запуск языковой модели.
- Qwen3 1.7B (`qwen3:1.7b`) — модель, используемая сервисом Ollama.

### Запуск и инфраструктура
- Docker и Docker Compose — альтернативный запуск frontend, backend и Ollama в контейнерах.
- Nginx — раздача статических frontend-файлов в Docker.
- Git — контроль версий.

## Требования

Для локального запуска:
- Windows, macOS или Linux;
- Python 3.12;
- современный браузер;
- доступ к интернету для загрузки frontend-библиотек через CDN.

Для запуска через контейнеры дополнительно нужны Docker Desktop (Windows/macOS) или Docker Engine и Docker Compose.

## Запуск локально

### 1. Скачайте проект и откройте его в VS Code

Откройте терминал в корневой папке проекта — там, где находятся `index.html`, `app.js` и `docker-compose.yml`.

### 2. Установите зависимости backend

В PowerShell:

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если команда `py -3.12` не найдена, установите Python 3.12 и убедитесь, что он доступен через Python Launcher. В случае запрета активации виртуального окружения в PowerShell можно выполнить `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`, а затем повторить активацию.

### 3. Запустите backend

Оставаясь в папке `backend`, выполните:

```powershell
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

API:
- Проверка backend: http://127.0.0.1:8000/health
- Swagger UI: http://127.0.0.1:8000/docs
- Проверка Ollama: http://127.0.0.1:8000/health/ollama

При первом запуске база SQLite создаётся автоматически.

### 4. Запустите frontend во втором терминале

Откройте второй терминал VS Code, перейдите в корневую папку проекта и выполните:

```powershell
python -m http.server 5500
```

Откройте в браузере http://localhost:5500.

Не открывайте `index.html` напрямую через `file://` — используйте локальный HTTP-сервер.

### 5. Запустите Ollama для ИИ-функций

Установите Ollama с официального сайта https://ollama.com/download и запустите приложение. Затем в отдельном терминале выполните:

```powershell
ollama pull qwen3:1.7b
```

Проверьте, что Ollama доступна на `http://localhost:11434`. Если Ollama не запущена, некоторые функции ассистента будут работать с резервными ответами или без результата от модели.

## Запуск через Docker Compose

Из корневой папки проекта выполните:

```powershell
docker compose up --build
```

При первом запуске Docker загрузит образы и модель Ollama; это может занять некоторое время и потребовать несколько гигабайт свободного места.

Адреса:
- Frontend: http://localhost:8080
- Backend API: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- Ollama: http://localhost:11434

Чтобы остановить контейнеры:

```powershell
docker compose down
```

Чтобы остановить контейнеры и удалить сохранённый том Ollama с загруженной моделью:

```powershell
docker compose down -v
```

Команда с `-v` удаляет том с данными Ollama. Используйте её только если готовы загрузить модель заново.

## Быстрая проверка

1. Откройте http://127.0.0.1:8000/health — ожидается ответ со статусом `ok`.
2. Откройте http://127.0.0.1:8000/docs.
3. Выполните `GET /api/applications`, чтобы проверить доступ к хранилищу заявок.
4. Создайте тестовую заявку через `POST /api/applications`.
5. Убедитесь, что новая заявка получает статус `scoring`: результат скоринга является предварительной оценкой, а не автоматическим одобрением.
6. Откройте http://localhost:5500 и проверьте интерфейс клиента и банковского специалиста.

## Основной сценарий демонстрации

1. Войти в демонстрационный кабинет.
2. Посмотреть информацию о компании и кредитные продукты.
3. Открыть ИИ-ассистента и описать потребность в финансировании.
4. Создать заявку и посмотреть её статус.
5. Переключиться в банковский режим и открыть заявку.
6. Принять решение по заявке.
7. Вернуться в кабинет клиента и проверить отображение решения.
8. Пройти демонстрационный сценарий принятия предложения и подписания.

## Важные ограничения прототипа

- Используются демонстрационные данные и смоделированные интеграции; реальные кредитные решения и перечисления денег не выполняются.
- Авторизация и переключение ролей предназначены для демонстрации и не заменяют полноценную систему доступа.
- Не используйте прототип для хранения реальных финансовых или персональных данных без реализации аутентификации, авторизации, аудита и защиты данных.
- Файлы документов не загружаются в backend как полноценное файловое хранилище.
- Данные внешних источников, включая сведения о компании и кредитные проверки, могут быть смоделированы.
- Frontend загружает библиотеки через CDN, поэтому для первого открытия нужен доступ к интернету.
- SQLite используется для локального прототипа. Для промышленного развёртывания следует отдельно спроектировать конфигурацию PostgreSQL, миграции, резервное копирование и управление секретами.
