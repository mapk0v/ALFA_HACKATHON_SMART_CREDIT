# Исправления интеграции и процесса заявок

## Главное исправление: заявки не одобряются автоматически

- При создании любая новая заявка получает статус `scoring` (ожидает решения специалиста).
- Скоринг сохраняется как предварительная рекомендация и оценка риска; он не выставляет финальный статус.
- Финальное решение принимается отдельным действием банковского специалиста: `approved`, `counter` или `rejected`.
- Сервер не разрешает повторно принимать решение по уже обработанной заявке.
- Подписание доступно только после принятия одобренного предложения.
- Выдача в демо-сценарии доступна только после подписания. Реальные денежные переводы не выполняются.
- При запуске старые записи, которые старая версия автоматически одобрила скорингом без истории решения специалиста, возвращаются в очередь `scoring`.

## Исправлены контракты API

- Создание заявки корректно принимает `product_id` и `productId`.
- Ответы создания и списка заявок используют единый формат полей, который ожидает интерфейс.
- В заявке сохраняются компания, ИНН, продукт, ставка, платёж, счёт, код демо-подписания, скоринговый балл, факторы и история.
- При принятии альтернативного предложения обновляются сумма, срок и платёж.
- Чат больше не называет предварительный сигнал скоринга официальным отказом.

## Исправлена конфигурация окружения

- Добавлен `greenlet` в зависимости SQLAlchemy async.
- Docker-образ backend использует Python 3.12 для совместимости с закреплёнными зависимостями.
- Ollama URL настраивается через `OLLAMA_BASE_URL`, поэтому работает и локально, и в Docker.
- Корневой `docker-compose.yml` запускает frontend, backend и Ollama вместе.

## Запуск в VS Code без Docker

Терминал 1, папка `backend`:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

Терминал 2, корень проекта:

```powershell
python -m http.server 5500
```

Откройте `http://localhost:5500`. API: `http://127.0.0.1:8000/docs`.

Если зависимости уже установлены в виртуальном окружении, активируйте его перед запуском команд.
